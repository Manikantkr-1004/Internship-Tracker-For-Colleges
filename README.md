# Internship Tracker for Colleges

A web application for colleges to help students log internship details, upload reports, and obtain faculty approval. Built with React, this project demonstrates role-based dashboards, form submissions, and a simple approval workflow.

## Features

- **Student Dashboard:**  
  - Log new internship details (company, role, duration, supervisor, description)
  - Upload internship reports (PDF/doc)
  - Track submission and approval status
- **Faculty Dashboard:**  
  - View and review student submissions
  - Approve or reject reports with comments
  - Track history of approvals
- **Role-based Access:** Simulated login for students and faculty
- **Temporary Data Storage:** Uses local state or localStorage for demo purposes
